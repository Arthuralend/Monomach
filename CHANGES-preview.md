# WindowsFX — предварительная версия оформления и совместимости

База: Arthuralend/WindowsFX, коммит 31ba8da24eb0355d633e1ee4008d6b5c4caa44b8.

## Изменения

- Плоские SVG-иконки без градиентных заливок и бликов. Общий двухцветный знак для меню «Пуск», Android-иконки и SVG-логотипа.
- Полные палитры «Мята» и «Бордо и беж», каждая со светлым и вечерним вариантом. Параметры → Персонализация → Темы. Существующие настройки оформления сохраняются.
- Общий **текстовый** буфер с Android через ClipboardManager, в том числе внутри Craft-приложений. Чтение запрашивается при вставке; фонового опроса и истории буфера нет. Изображения и файлы в общий буфер этим изменением не добавлены.
- Photostore: на Android по умолчанию используется встроенный режим `?cpu`, обходящий GPU-композитор изображения. Это обход предполагаемой причины полупрозрачности больших фото, а не подтверждённое устранение дефекта на устройстве пользователя. Скорость обработки больших файлов может снизиться. Для сравнения доступен режим GPU в разделе тем; изменение действует после закрытия и нового запуска Photostore. Альфа-канал исходного изображения не изменяется.
- Настройка непрозрачности применяется к экранному холсту; промежуточные холсты и настройки premultiplied alpha сохраняются.
- Переключение окон восстанавливает поле ввода, нажатия внутри Craft активируют окно, скрытые окна не получают фокус. Исправлен возврат после «Свернуть все» и очистка состояния перетаскивания при отмене жеста.
- Добавлен обход окон по Alt+Tab/Alt+Shift+Tab, если сочетание передано приложению. Android может перехватывать Alt+Tab для переключения системных приложений.
- targetSdk 35, minSdk 26 (Android 8). Для Android 15+ учтены края экрана, вырезы и область экранной клавиатуры. Явный MIME-тип WebAssembly для загрузки Craft.

## Проверено

- Сборка `:app:assembleRelease` завершилась успешно (JDK 17, Gradle 8.11.1, SDK 35).
- Все собственные JS-файлы проходят синтаксическую проверку Node.
- Два интеграционных теста проходят: конкурентные запросы буфера/отказ доступа/браузерный вариант и сохранение alpha у промежуточных холстов.
- В браузере проверены обе светлые палитры; переключение Проводник → Параметры → Проводник восстанавливает поле поиска и введённый текст. «Свернуть все» и повторное нажатие возвращают оба окна и фокус поиска.
- ARM64 APK установлен и запущен на Android preview API 37 в эмуляторе с размером страниц 16384 байта. После запуска процесс работает; падений приложения в проверенном журнале нет. Это проверка запуска, не полная проверка всех функций.
- Все четыре нативные ARM64-библиотеки APK имеют ELF LOAD alignment 16384.
- В APK включены три опубликованных Craft-движка; SHA-256 архивов сверены с метаданными релиза `craft-assets`.

## Что ещё требует проверки

- Полупрозрачность больших фото, скорость и переключение окна Photostore на реальном устройстве пользователя. Файл с воспроизводимой ошибкой и модель устройства не предоставлены.
- Буфер между WindowsFX и другими Android-приложениями на реальном устройстве; текущие автоматические тесты используют имитацию Android-ответов.
- Android 8–16, Huawei и разные GPU не проверены на физических устройствах. Нужен актуальный Android System WebView; minSdk сам по себе не гарантирует поддержку всех веб-возможностей старым WebView.
- Для HarmonyOS с поддержкой APK используется Android-версия без зависимости от Google Play Services. Тестирования на Huawei не было. **Нативная HAP-версия для HarmonyOS NEXT/5+ не создана**, она требует отдельного переноса Android-мостов и проверки в DevEco Studio.

Обновление: тестовый APK имеет versionCode 24, versionName 0.4.24 и подписан существующим ключом проекта. Перед установкой поверх важной рабочей среды рекомендуется сохранить документы. Этот файл не является опубликованным стабильным релизом.
